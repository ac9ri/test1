## 1. 문제와 목적

- 사실: 작업 디렉터리는 비어 있다. 기존 코드·DLL·샘플 이미지·설정이 없다.
- 사실(사용자 1차 답변, 2026-10-11):
  - 대표 분석은 SFR 해상도 평가이고, 전체 이미지에 대한 평가도 함께 원한다.
  - 과제 DLL은 C 함수다.
  - raw는 헤더 없는 베이어 덤프이며 과제별로 고정이지만, 메타를 입력받거나 추정할 수 있으면 추정해서 진행하기를 원한다.
  - 사내 GLM은 "클로드 데스크톱 같은 사내 프로그램"을 통해 사용한다. API 접속 정보는 언급되지 않았다.
  - 실행 주체는 미정이고 처리량·허용 처리 시간 목표는 없다.
  - 샘플 차트·이미지 몇 개를 확보할 예정이다.
  - 사내 해커톤에서 사내 LLM으로 AI Agent를 약 12시간 안에 만들어야 한다.
- 해석: LLM을 프로그램에서 호출할 API가 없으므로 "Agent"는 사내 프로그램(호스트) 안에서 돌아가야 한다. 호스트가 MCP 같은 도구 연결을 지원하면 우리 코드는 도구 서버가 되고, 호스트의 GLM이 도구를 순서대로 호출해 판별·해석을 맡는다. 수치 계산은 도구 안의 결정적 코드가 한다.
- 가정 A-01: "차트"는 카메라 화질 평가용 테스트 차트다. 사용자 답변의 SFR 평가로 뒷받침된다. 확정.
- 가정 A-06: 사내 프로그램은 클로드 데스크톱처럼 MCP 서버(stdio)를 등록해 도구를 호출할 수 있다. 틀리면 설계 2.3절의 연동 사다리에서 다음 단계를 쓴다(Q-07).

**목적:** 해커톤 12시간 안에, 호스트 프로그램에서 "이 폴더 이미지 분석해줘"라고 말하면 차트 판별 → SFR DLL 계산 + 전체 이미지 평가 → 판정 → 보고서까지 끝나는 Agent를 시연한다. 그 뒤에도 차트·과제·DLL을 설정으로 추가할 수 있는 구조를 남긴다.

## 8. 예외와 실패 시 기대 동작

| 상황 | 기대 동작 |
|---|---|
| 지원하지 않는 확장자 | 도구 오류 메시지 반환, 폴더 처리는 계속 |
